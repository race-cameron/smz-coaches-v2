GUARDIANS BY THE DOORS
======================
The .png files here are the stand-in Guardians (flat cut-outs that turn to face you).

To swap in a real 3D Guardian, add a model file to this folder with one of these exact names:

  safety.glb      Hiro
  unity.glb       Mrs. Picklefrog
  willpower.glb   Master Commander
  energy.glb      Woodsy the Wizard
  reaction.glb    Serenity

The vault finds it automatically, stands it on the plinth, sizes it to about 2.1 m tall,
and hides the cut-out. No code changes needed. Keep each model under about 5 MB.
